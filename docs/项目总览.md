# PixelLauncher 项目总览

## 项目边界

PixelLauncher 同时包含 Launcher 产品、像素 UI SDK 和独立展示应用，主工程维护三个模块：

```text
:app -> :pixel-engine
:showcase -> :pixel-engine
```

`app` 负责产品行为，`pixel-engine` 负责可复用 UI 基础设施，`showcase` 负责独立展示引擎能力。当前不保留历史样例、Compose adapter 和 benchmark target，也不按普通源码职责拆分 SDK 子模块。

## `app`

`app` 包含 Launcher 的应用入口、数据投影、搜索、抽屉、设置、相机/视觉能力和页面组合。它可以调用 `pixel-engine` 的公开 API，但不得依赖引擎的 `internal` 包。

产品专用文案、图标、布局策略和业务状态应留在 `app`。只有具备中性命名、稳定参数和独立测试的能力才适合进入 SDK。

## `showcase`

`showcase` 是可直接安装运行的 Android Application，只通过 `pixel-engine` 的公开 API 展示引擎能力。它不承载 Launcher 产品逻辑，也不参与 SDK 发布。

## `pixel-engine`

`pixel-engine` 是统一 Android Library，内部代码仍按包分层：

- `com.purride.pixelcore`：颜色、像素缓冲、位图字体、资源与精灵。
- `com.purride.pixelui`：Widget、Element、RenderObject、主题、标准组件，以及路由、返回栈、恢复与转场。
- `com.purride.pixelui.host`：Android View Host、帧调度、输入与生命周期。
- `com.purride.pixelui.testing`：确定性测试器、Finder 与断言。
- `com.purride.pixelui.debug`：检查器和诊断能力。

这些是源码职责边界，不是 Gradle 或 Maven 模块边界。需要隔离实现时应先通过 package、`internal` 可见性和 API 门禁解决，不应默认增加模块。

## 构建与发布

SDK 只发布 `com.purride:pixel-engine:1.0.0`。发布物包含 AAR、POM、Gradle module metadata、sources 和 Javadoc/KDoc，并由以下能力保护：

- Kotlin API 与 JVM binary API 基线。
- Metalava 当前 API 签名基线。
- AAR 大小、class、method 与依赖预算。
- 依赖锁定和 Gradle dependency verification。
- 隔离 Maven 消费者、R8 和自定义 RenderObject SPI 验证。
- SBOM、来源证明、checksum 与签名演练。

## 测试层次

```text
源码规则和工具单测
        ↓
pixel-engine JVM 单测
        ↓
app JVM 单测
        ↓
pixel-engine instrumentation
        ↓
showcase APK 构建
        ↓
隔离发布消费者与供应链校验
```

性能采集和长时间 soak 已从当前目标移出；后续恢复时应建立独立、可重复的性能工程和设备基线。

## 开发规则

1. 新能力先判断属于产品还是通用 SDK。
2. 新公开类型、方法、类和字段必须有必要的中文注释。
3. 修改公开 API 时同步更新 API/ABI 基线、文档和兼容测试。
4. 不用新增 Gradle 模块表达普通源码分层。
5. 不把生成报告、IDE 缓存或一次性验收记录提交到仓库。
6. 主工程结构变化后必须执行 `./gradlew projects`，确认只有 `app`、`pixel-engine` 和 `showcase` 三个模块。

## 常用入口

```bash
./gradlew :pixel-engine:testDebugUnitTest :app:testDebugUnitTest
./gradlew :pixel-engine:lintDebug :app:lintDebug
./gradlew :pixel-engine:checkBinaryApi :pixel-engine:checkMetalavaApi
./gradlew :app:assembleDebug :showcase:assembleDebug :pixel-engine:assembleRelease
bash tools/pixel-publication-validation.sh
```
