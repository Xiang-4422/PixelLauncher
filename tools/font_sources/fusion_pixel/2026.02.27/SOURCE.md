# Fusion Pixel Font 2026.02.27

这些 BDF 源文件来自 Fusion Pixel Font 官方 `2026.02.27` GitHub Release：

https://github.com/TakWolf/fusion-pixel-font/releases/tag/2026.02.27

仓库仅保存设置页可达的 8PX、10PX、12PX，包含 proportional/monospaced 与
latin/zh_hans 组合。文件使用 `gzip -n` 确定性压缩；`fonts/font_catalog.json`
记录压缩文件 SHA-256。字体使用 SIL Open Font License 1.1。
