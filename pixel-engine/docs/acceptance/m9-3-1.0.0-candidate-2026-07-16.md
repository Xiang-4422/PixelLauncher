## 首轮失败与修复

版本切换后的第一次供应链演练没有通过：`writePixelReleaseDependencyGraph` 被 Gradle 判定为
UP-TO-DATE，错误复用了 snapshot 依赖图，检查器因此找不到预期的 `1.0.0` 内部组件。这是发布缓存
正确性缺陷，不是网络或性能问题。

根任务现已把九个最终 GAV 作为显式输入，供应链入口在构建前删除旧依赖图。重新生成的九个内部
package URL 全部以 `@1.0.0` 结尾，随后完整签名供应链演练通过。没有通过放宽校验、改写失败报告或
跳过依赖图门禁来处理该问题。

第一次完整 release gate 随后发现第二个版本切换缺陷：七个隔离 artifact 消费者已经声明并真实解析
`1.0.0`，但传递依赖断言仍匹配内部 `0.1.0-SNAPSHOT`，因此 runtime 消费者在正确的 Gradle 依赖图
上被误判失败。七个脚本的断言已统一为 `1.0.0`，并新增静态回归测试保证正式消费者不会重新引用
snapshot 模式；七个消费者逐项通过后，完整 release gate 从头复跑成功。
