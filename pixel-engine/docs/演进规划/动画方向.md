## 当前已具备

### Layer 1：动画核心

- `PixelTicker`
- `PixelTickerProvider`
- `PixelTickerProvider.createTicker(maxFps = ...)`
- `PixelAnimationController`
- `PixelAnimationStatus`
- `Animation<Float>`
- `Tween<T>`
- `IntTween`
- `EdgeInsetsTween`
- `OffsetTween`
- `PixelColorTween`
- `Curves`
- `CurvedAnimation`

核心默认保持可预测：controller 本身线性推进，视觉离散感交给 curve 或低 FPS ticker。

### Layer 2：隐式动画 widget

隐式动画 widget 默认 `Curves.Step(8)`，让像素 UI 保留阶梯式过渡。

- `TweenAnimationBuilder`
- `AnimatedContainer`
- `AnimatedOpacity`
- `AnimatedPadding`
- `AnimatedAlign`
- `AnimatedPositioned`
- `AnimatedSwitcher`
- `AnimatedSprite`
- `PixelNavigator` route slide / fade transition

### Layer 3：显式工具

- `AnimatedBuilder`
- `createTicker(maxFps = ...)`

`AnimatedBuilder` 接收任意 `Listenable`，适合把不变子树通过 `child` 参数复用，减少每帧重建成本。

## 设计取向

- 默认离散优先：隐式动画默认 `Curves.Step(8)`。
- 显式可平滑：用户可改用 `Curves.Linear` / `EaseIn` / `EaseOut` / `EaseInOut`。
- 低 FPS 是一等能力：`createTicker(maxFps = 15)` 可让单个 ticker 降帧，不影响全局。
- 颜色走 ARGB：当前用 `PixelColorTween` 做通道补间。
- 透明度仍按 `0` / `0.5` / `1` 三档量化；`0.5` 档通过 `Opacity` 走真实 `srcOver` alpha blend。
