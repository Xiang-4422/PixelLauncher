## 当前 API

### Ticker

```kotlin
val ticker = provider.createTicker(maxFps = 15) { elapsedNanos ->
    // elapsedNanos 是 ticker 启动后的真实累计时间
}
ticker.start()
ticker.stop()
ticker.dispose()
```

`maxFps == null` 时每个 vsync 都派发；`maxFps > 0` 时按最小间隔 drop 中间帧。

### Controller

```kotlin
val controller = PixelAnimationController(
    duration = 300.milliseconds,
    vsync = provider,
)

controller.forward()
controller.reverse()
controller.repeat(reverse = true)
controller.stop()
controller.reset()
controller.dispose()
```

`PixelAnimationController` 继承 `ChangeNotifier`，可配合 `AnimatedBuilder` 或 `context.watch(controller)` 使用。

### Tween

当前 tween：

- `IntTween`
- `EdgeInsetsTween`
- `OffsetTween`
- `PixelColorTween`
- `PixelGradientTween`

`PixelColorTween` 逐 ARGB 通道补间；`PixelGradientTween` 要求 begin/end 是同类 gradient 且 stop 数一致，会补间 linear/radial 几何参数、stop offset 和 stop color。

### 隐式 widget

```kotlin
TweenAnimationBuilder(
    tween = IntTween(begin = 0, end = 40),
    duration = 300.milliseconds,
    vsync = provider,
) { _, value ->
    Container(width = value, height = 12, borderColor = PixelColor.White)
}
```

默认曲线是 `Curves.Step(8)`。

## 保留的设计约束

- 隐式动画默认离散优先：`Curves.Step(8)`。
- Layer 1 默认线性推进，不在 controller 里硬编码像素美学。
- 透明度仍按三档量化；`0.5` 档通过 `Opacity` 走真实 `srcOver` alpha blend。
- 不做 Hero、SpringSimulation、Lottie、Rive。
- Layer 4 route/list transition 需要等 Navigator 设计。
