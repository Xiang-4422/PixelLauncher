# 彩色系统实施记录

> 状态：历史实施记录。当前代码已经从早期“双模式彩色计划”进一步收敛为单一 ARGB `PixelBuffer` 路径。

最后更新：2026-05-25

---

## 当前代码状态

已落地：

- `PixelColor`：ARGB 32-bit value class，提供 `fromRgb` / `fromArgb` / `Transparent` / `Black` / `White`。
- `PixelBuffer`：单一 ARGB `IntArray` buffer，提供 `setPixel` / `getPixel` / `fillRect` / `drawRect` / `blit` / `blitRegion`。
- `PixelBufferPool`：按 `(width, height)` 分桶复用 `PixelBuffer`。
- `PixelBitmap`：不可变 ARGB 位图源，可从 Android `Bitmap` 拷贝。
- 公开 widget 颜色参数：`Text(color)`、`Container(fillColor, borderColor)`、`DecoratedBox`、`OutlinedButton`、`TextField`、`Line`、`Circle`、`Image`。
- 动画：`PixelColorTween`、`AnimatedContainer(borderColor)`。
- 宿主：`PixelHostSetupConfig.backgroundColor`、`PixelHostView.pixelGridColor`。

已移除 / 未保留：

- `PixelTone`
- `PixelPalette`
- `PixelTheme`
- `PixelColorMode`
- `MonoPixelBuffer`
- `ColorPixelBuffer`
- `PixelThemeTokens`
- `ThemeData`

## 与早期 Phase A-E 的对应

早期计划把彩色系统拆成：

1. 渲染层基础设施。
2. 主题与 token 重构。
3. 公开 widget API 扩展。
4. Mode 切换与 host 集成。
5. 文档与验收。

当前最终形态只保留其中真正需要的部分：

- 渲染层基础设施：完成，并简化为单一 ARGB buffer。
- 公开 widget API：完成，直接暴露 `PixelColor`。
- 动画补间：完成，`PixelColorTween` 已可用。
- 主题 / token / mode：未保留，应用层自行定义主题对象并显式传颜色。

## 后续增量建议

不要恢复 Mono / Color 双模式。后续如果继续扩展色彩能力，建议拆成独立任务：

- 更完整的 alpha / blend mode 策略；当前已默认使用 straight alpha `srcOver`，premultiplied 策略暂未引入。
- gradient widget。
- palette JSON schema 或 app 层主题 helper。
- `AnimatedContainer(fillColor)`。
- `Path` / `Polygon` 已有基础图形原语；后续是 stroke width、gradient 和更多 blend mode。
