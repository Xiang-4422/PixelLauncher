# Widget 目录

pixel-engine 内置 widget 按职责分组。每个 widget 都是 `Widget` 接口的实例，可以自由嵌套组合。本文档列出公开 widget 的签名与典型用法。

> **import：** 所有 widget 都在 `com.purride.pixelui` 包，统一 `import com.purride.pixelui.*` 即可。

## 布局类

### `Row` / `Column`

线性排列子节点。`Row` 水平、`Column` 垂直。

```kotlin
Row(
    children: List<Widget>,
    spacing: Int = 0,
    mainAxisAlignment: MainAxisAlignment = MainAxisAlignment.START,
    crossAxisAlignment: CrossAxisAlignment = CrossAxisAlignment.START,
    mainAxisSize: MainAxisSize = MainAxisSize.MIN,
)

Column(/* 同上 */)
```

- `spacing` —— 相邻 child 之间的间距（像素）
- `mainAxisAlignment` —— 主轴上的对齐：`START` / `CENTER` / `END` / `SPACE_BETWEEN` / `SPACE_AROUND` / `SPACE_EVENLY`
- `crossAxisAlignment` —— 交叉轴对齐：`START` / `CENTER` / `END` / `STRETCH`

### `Stack`

层叠排列。后加入的 child 在上层。配合 `Positioned` 控制每个 child 的偏移。

```kotlin
Stack(
    children = listOf(
        Container(/* 背景 */),
        Positioned(top = 4, left = 4, child = Text("OVERLAY")),
    ),
)
```

### `Padding`

为 child 添加内边距。三种重载：

```kotlin
Padding(child, all = 4)                                   // 四边相等
Padding(child, padding = EdgeInsets.symmetric(horizontal = 2, vertical = 4))
Padding(child, horizontal = 4, vertical = 2)              // 对称简写
```

### `PaddingDirectional`

与 `Padding` 相同，但接受 `EdgeInsetsDirectional`（start/end 感知文字方向），适合 RTL 场景：

```kotlin
PaddingDirectional(child, padding = EdgeInsetsDirectional(start = 8, end = 4))
```

### `SizedBox`

固定尺寸的空盒（占位 / 间隔）：

```kotlin
SizedBox(width = 10, height = 10)
SizedBox(height = 4)        // 仅在 Column 中做垂直间距
```

### `Align` / `Center`

把 child 在自身可用区域内对齐。`Center` 等价于 `Align(alignment = Alignment.CENTER)`。

```kotlin
Center(child = Text("HELLO"))
Align(child = Text("HELLO"), alignment = Alignment.TOP_END)
```

### `AlignDirectional`

与 `Align` 相同，但使用 `AlignmentDirectional`（start/end 感知方向）：

```kotlin
AlignDirectional(child, alignment = AlignmentDirectional.TOP_START)
```

### `Wrap`

水平主轴自动换行布局，适合 chip、图标矩阵等固定小块：

```kotlin
Wrap(
    children = chips,
    spacing = 2,
    runSpacing = 2,
)
```

### `AspectRatio` / `ConstrainedBox` / `FittedBox`

最小约束组件：

```kotlin
AspectRatio(aspectRatio = 16f / 9f, child = preview)
ConstrainedBox(
    constraints = PixelBoxConstraints(minWidth = 24, minHeight = 12),
    child = Text("OK"),
)
FittedBox(child = preview) // contain-only，按整数像素 nearest 缩放并居中
```

### `Expanded` / `Flexible` / `Spacer`

在 `Row` / `Column` 中按 flex 因子分配剩余空间：

```kotlin
Row(children = listOf(
    Text("LEFT"),
    Spacer(),               // 占满中间所有剩余空间
    Text("RIGHT"),
))

Column(children = listOf(
    Text("HEADER"),
    Expanded(child = ListView(/* ... */)),  // 占满 Column 剩余高度
    Text("FOOTER"),
))
```

- `Expanded` = `Flexible` + `fit = FlexFit.TIGHT`（强制填满 flex 分配）
- `Flexible` 默认 `fit = LOOSE`（最大可达到 flex 分配，但允许更小）
- `Spacer` = `Expanded(child = SizedBox())`

## 内容类

### `Text`

显示一行或多行文本。

```kotlin
Text(
    data: String,
    style: TextStyle = TextStyle.Default,
    color: PixelColor? = null,          // 覆盖文本颜色
    textAlign: TextAlign = TextAlign.START,
    softWrap: Boolean = false,
    maxLines: Int = 1,
    overflow: PixelTextOverflow = PixelTextOverflow.CLIP,
)
```

样式：
- `TextStyle.Default` —— 默认白色像素字体
- `TextStyle(color = PixelColor.fromRgb(...))` —— 自定义颜色
- `TextStyle(textRasterizer = customFont)` —— 单条文本覆盖字体栅格器

彩色文本：
```kotlin
Text("hello", color = PixelColor.fromRgb(0, 200, 255))
```

多行：
```kotlin
Text(
    "LONG PARAGRAPH ...",
    softWrap = true,
    maxLines = 4,
    overflow = PixelTextOverflow.ELLIPSIS,
)
```

### `RichText`

带多 span 样式的富文本。

```kotlin
RichText(
    spans = listOf(
        PixelTextSpan(text = "NORMAL "),
        PixelTextSpan(
            text = "ACCENT",
            style = TextStyle(color = PixelColor.fromRgb(255, 200, 0)),
        ),
    ),
)
```

### `Container`

带可选填充 / 边框 / 对齐 / 尺寸的容器。

```kotlin
Container(
    child = Text("INSIDE"),
    width = 40,
    height = 16,
    fillColor = PixelColor.fromRgb(12, 18, 24),
    borderColor = PixelColor.fromRgb(120, 220, 255),
    alignment = Alignment.CENTER,
    padding = EdgeInsets.all(2),
)
```

`ContainerDirectional` 接受 `paddingDirectional`（START/END），其余等价。

### `DecoratedBox`

只做装饰（填充 + 边框），不参与尺寸约束。可包 / 不包 child：

```kotlin
DecoratedBox(
    child = Text("BORDERED"),
    fillColor = PixelColor.fromRgb(0, 0, 0),
    borderColor = PixelColor.fromRgb(255, 200, 0),
)
```

### `Image`

把不可变 [`PixelBitmap`](#pixelbitmap) 1:1 blit 到目标 buffer。

```kotlin
val bitmap: PixelBitmap = PixelBitmap.fromAndroidBitmap(androidBitmap)
Image(bitmap = bitmap)
```

- **Layout**：intrinsic 尺寸 = bitmap (width, height)，再按父约束 clamp。
- **Paint**：行级 `System.arraycopy`，超出 layout size 自动裁剪，不缩放。
- 缩放由调用方完成（如 `Bitmap.createScaledBitmap`）后再构造 `PixelBitmap`。
- 暂不支持 tint / 颜色变换。如需上色，构造 `PixelBitmap` 前自行处理像素数组。

#### `PixelBitmap`

不可变的像素位图源（ARGB IntArray）。与 `PixelBuffer` 区别：buffer 是
engine 每帧重用的可变绘制目标，bitmap 是用户提供的常驻图像源。

```kotlin
// 从 Android Bitmap 拷贝
val bitmap = PixelBitmap.fromAndroidBitmap(androidBitmap)

// 程序化构造
val pixels = IntArray(8 * 8) { i -> PixelColor.fromRgb(i, 0, 0).argb }
val bitmap = PixelBitmap(width = 8, height = 8, pixels = pixels)
```

#### `PixelBitmapAssetLoader` / `PixelBitmapResourceLoader`

从 Android asset 或 resource 解码 PNG 到 `PixelBitmap`：

```kotlin
val assetBitmap = PixelBitmapAssetLoader(context.assets).load("pixel/sample.png")
val resBitmap = PixelBitmapResourceLoader(context.resources).load(R.drawable.sample)
```

解码失败会抛 `PixelBitmapLoadException`，消息包含 asset 路径或 resource id。

### `Sprite`

从 [`PixelSpriteSheet`](#pixelspritesheet) 中选择一个 frame 1:1 blit，不缩放。

```kotlin
val sheet = PixelSpriteSheet(
    bitmap = bitmap,
    frames = listOf(
        PixelBitmapRegion(left = 0, top = 0, width = 8, height = 8),
        PixelBitmapRegion(left = 8, top = 0, width = 8, height = 8),
    ),
)

Sprite(sheet = sheet, frameIndex = 0)
```

- `frameIndex` 越界会抛 `IllegalArgumentException`。
- frame region 必须完全落在 bitmap 内。
- bitmap 像素按 `srcOver` 写入目标 buffer；`alpha = 0` 不覆盖目标像素，`alpha = 255` 走 opaque fast path。

#### `PixelSpriteSheet`

不可变 sprite sheet，持有一张 `PixelBitmap` 和一组 frame region。

```kotlin
data class PixelBitmapRegion(left: Int, top: Int, width: Int, height: Int)
data class PixelSpriteSheet(bitmap: PixelBitmap, frames: List<PixelBitmapRegion>)
```

`frames` 不能为空；region 的 `left/top >= 0`，`width/height > 0`。

`PixelSpriteSheetJsonLoader` 可解析最小 JSON manifest：

```json
{"bitmap":"sprites/runner.png","frames":[{"left":0,"top":0,"width":8,"height":8}]}
```

`parseDefinition` 返回 `PixelSpriteSheetDefinition`，包含 bitmap path 和 frame regions；`load(json, bitmap)` 会直接构造 `PixelSpriteSheet` 并复用 region 越界校验。

#### `PixelResourceCache`

按 key 缓存 bitmap 和 sprite sheet，适合 host、demo scene 或业务资源 owner 持有：

```kotlin
val cache = PixelResourceCache()
val bitmap = cache.getBitmap("icons/home") { PixelBitmapAssetLoader(assets).load("icons/home.png") }
val sheet = cache.getSpriteSheet("runner") { PixelSpriteSheetJsonLoader.load(json, bitmap) }
cache.remove("runner")
cache.clear()
```

## 图形原语

非矩形图形 widget。矩形请直接用 [`Container`](#container) / [`DecoratedBox`](#decoratedbox)。

### `Line`

直线（Bresenham 算法）。端点相对 widget 左上角。

```kotlin
Line(
    startX = 0, startY = 0,
    endX = 7, endY = 3,
    color = PixelColor.fromRgb(0xE0, 0xE0, 0xE0),
)
```

- **Layout**：intrinsic 尺寸 = `(max(startX, endX) + 1, max(startY, endY) + 1)`，父约束更紧时被 clamp。
- **Paint**：逐像素 `setPixel`，线宽固定 1。

### `Circle`

圆形 widget。圆心 = 当前 layout box 中点。

```kotlin
Circle(radius = 4, color = PixelColor.fromRgb(0xFF, 0xC0, 0x40))             // 填充
Circle(radius = 4, color = PixelColor.fromRgb(0xE0, 0xE0, 0xE0), filled = false) // 描边
```

- **Layout**：intrinsic 尺寸 = `(2 * radius + 1, 2 * radius + 1)`，父约束更紧时被 clamp。
- **Paint**：
  - `filled = true`（默认）：逐 scanline 填充。
  - `filled = false`：中点圆轮廓算法，单像素线宽。

适合 radio dot、状态指示、装饰圆点等场景。

### `Polygon`

多边形 widget。`filled = true` 使用 scanline 填充；`filled = false` 连接相邻点并自动闭合轮廓。

```kotlin
Polygon(
    points = listOf(PixelPoint(0, 6), PixelPoint(4, 0), PixelPoint(8, 6)),
    color = PixelColor.fromRgb(255, 192, 64),
    filled = true,
)
```

### `Path`

路径 widget。当前 v1 支持 `MoveTo` / `LineTo` / `Close`，不支持曲线、stroke width 或 gradient。

```kotlin
Path(
    path = PixelPath(
        commands = listOf(
            PixelPathCommand.MoveTo(PixelPoint(0, 5)),
            PixelPathCommand.LineTo(PixelPoint(3, 0)),
            PixelPathCommand.LineTo(PixelPoint(6, 5)),
            PixelPathCommand.Close,
        ),
    ),
    color = PixelColor.White,
)
```

`closed = true` 时，即使命令里没有 `Close`，也会把最后一个点连回当前 subpath 起点。

## 按钮与选择控件

### `OutlinedButton`

像素风边框按钮。

```kotlin
OutlinedButton(
    text: String,
    onPressed: (() -> Unit)?,
    style: ButtonStyle = ButtonStyle.Default,
    enabled: Boolean = true,
    fillColor: PixelColor? = null,   // 覆盖填充色
    borderColor: PixelColor? = null, // 覆盖边框色
)
```

- `onPressed = null` 等价于禁用态（不响应点击）
- `style` —— `ButtonStyle.Default` 或自定义 `ButtonStyle(...)`
- `fillColor` / `borderColor` —— 覆盖 `style` 中对应颜色
- `enabled = false` —— 显式禁用点击

```kotlin
OutlinedButton(
    text = "DELETE",
    onPressed = if (canDelete) ::doDelete else null,
    borderColor = PixelColor.fromRgb(255, 80, 80),
)
```

### `Icon` / `PixelIconData`

`Icon` 是 `PixelBitmap` 图标的轻量包装：

```kotlin
Icon(PixelIconData(bitmap))
```

### `ListTile`

常用列表行：`leading` / `title` / `subtitle` / `trailing` / `onTap`。

ListTile(

## 输入与焦点

### `TextField`

像素风文本输入框。需要先创建 `PixelTextFieldController` 和 `state`，详见 [状态管理](状态管理.md)。

```kotlin
private val tfController = PixelTextFieldController()
private val tfState = tfController.create()

TextField(
    state = tfState,
    controller = tfController,
    placeholder = "ENTER NAME",
    inputType = PixelInputType.TEXT,
    textInputAction = TextInputAction.DONE,
    onSubmitted = { value -> /* ... */ },
)
```

- `inputType` —— `TEXT` / `NUMBER` / `NUMBER_PASSWORD` / `EMAIL` / `PHONE` / `URL` / `PASSWORD`
- `textInputAction` —— 系统软键盘 action 按钮；公开枚举是 `PixelTextInputAction`，常用别名是 `TextInputAction`，取值为 `DONE` / `NEXT` / `SEND` / `SEARCH` / `GO`
- **光标**：聚焦且 enabled 且非 readOnly 时，自动按当前 `selectionStart` 绘制 1px 光标（颜色取自
  [`PixelTextFieldStyle.cursorColor`](#textfieldstyle)）。空文本时光标在内容区左缘，多行文本会按 selection 所在行定位。默认开启闪烁，可通过
  `TextFieldStyle(cursorBlinkEnabled = false)` 关闭，或用 `cursorBlinkPeriodMs` 调整周期。
- **选区 / composition**：`selectionStart != selectionEnd` 时绘制选区色；IME composition 区段在聚焦时绘制 1px 下划线。多行文本会按行拆分选区和 composition，不再把跨行范围画成一整块。
- **选词**：`PixelTextFieldController.selectWordAt(state, index)` 可按字符 index 选中 ASCII 单词；宿主双击和 `PixelTester.doubleTap` 会复用该语义。
- **selection handle**：非空 selection 会绘制 start/end 两个最小拖拽 handle，颜色由 `selectionHandleColor` 控制，可通过 `selectionHandlesEnabled = false` 关闭；readOnly/disabled 不绘制也不允许拖动。

### `Focus` / `FocusScope`

最小焦点系统用于键盘、手柄和 IME `NEXT` 行为。`FocusNode` 持有单个可聚焦节点状态，`FocusScopeNode` 持有作用域内的节点列表并按 `FocusTraversalPolicy` 遍历。默认策略是 `ReadingOrderFocusTraversalPolicy`，按 widget 构建顺序处理 `PixelFocusDirection.NEXT` / `PREVIOUS` / 方向键。

```kotlin
val nameFocus = FocusNode("name")
val nextFocus = FocusNode("next")

FocusScope(
    child = Column(
        children = listOf(
            Focus(
                node = nameFocus,
                autofocus = true,
                onKeyEvent = { event: PixelKeyEvent -> event.key == PixelKey.ENTER },
                child = Text("NAME"),
            ),
            Focus(node = nextFocus, child = Text("NEXT")),
        ),
    ),
)
```

- `PixelFocusManager.primaryFocus` 表示当前主焦点。
- `PixelKey.TAB` / `SHIFT_TAB` / `ARROW_*` 会触发默认遍历。
- focused node 的 `onKeyEvent` 优先处理 `PixelKeyEvent`，返回 `true` 时事件被消费。
- `TextField(textInputAction = TextInputAction.NEXT)` 提交后会触发焦点下一项遍历。

## 滚动 / 翻页

### `ListView`

固定 items 列表（已知所有 child）：

```kotlin
ListView(
    items = listOf(Text("A"), Text("B"), Text("C")),
    state = listState,
    controller = listController,
    spacing = 2,
)
```

### `ListViewBuilder`

按 index 构造列表（带可选 lazy 渲染）：

```kotlin
ListViewBuilder(
    itemCount = 100,
    itemBuilder = { index -> Text("ITEM $index") },
    state = listState,
    controller = listController,
    spacing = 2,
    itemExtent = 12,    // 必传以启用 lazy 渲染（每 item 固定高度，单位像素）
    cacheExtent = 1,    // 可见区上下额外预渲染的页数
)
```

> ⚠️ **lazy 与 eager 的分界**：`itemExtent` **传入时走固定高度 lazy 路径**（只构造可见区 + `cacheExtent` 范围内的 item）。如果 item 高度不固定，可以传 `estimatedItemExtent` 显式启用变高 lazy 路径。不传 `itemExtent` 且不传 `estimatedItemExtent` 时回退到 eager 路径：一次性调 `itemBuilder` 构造所有 `itemCount` 个 widget。
>
变高 lazy 示例：

```kotlin
ListViewBuilder(
    itemCount = 1_000,
    itemBuilder = { index ->
        SizedBox(
            height = if (index % 5 == 0) 18 else 10,
            child = Text("ROW $index"),
        )
    },
    state = listState,
    controller = listController,
    estimatedItemExtent = 12, // 显式 opt-in，未测 item 会先按该高度估算
    cacheExtent = 2,
)
```

`itemExtent` 优先级高于 `estimatedItemExtent`。`estimatedItemExtent <= 0` 会按 eager 兼容路径处理。

### `GridView` / `GridViewBuilder`

固定 cell 宽高的二维垂直滚动网格，复用 `PixelListState` / `PixelListController`：

```kotlin
GridViewBuilder(
    itemCount = 100,
    itemBuilder = { index -> Text("$index") },
    cellWidth = 12,
    cellHeight = 10,
    state = listState,
    controller = listController,
    spacing = 2,
    runSpacing = 2,
    cacheExtent = 1,
)
```

`GridView` 接收完整 `items` 列表；`GridViewBuilder` 只构造可见窗口和 cache 范围内的 item。当前网格只支持垂直滚动和固定 cell extent。

### `Scrollbar`

包裹任意使用 `PixelListState` 的垂直滚动区域（List/Grid/SingleChildScrollView），在右侧绘制像素窄条：

```kotlin
Scrollbar(
    state = listState,
    width = 2,
    thumbColor = PixelColor.White,
    child = GridViewBuilder(/* ... */),
)
```

### `ListViewSeparated`

在 items 之间插入分隔 widget：

```kotlin
ListViewSeparated(
    itemCount = 20,
    itemBuilder = { i -> Text("ROW $i") },
    separatorBuilder = { _ -> DecoratedBox(fillColor = PixelColor.fromRgb(80, 80, 80)) },
    state = listState,
    controller = listController,
)
```

`ListViewSeparated` 是 eager API，会一次性构造全部 item 和 separator。长列表请使用固定高度 lazy 版本：

```kotlin
ListViewSeparatedBuilder(
    itemCount = 1_000,
    itemBuilder = { i -> Text("ROW $i") },
    separatorBuilder = { _ -> DecoratedBox(fillColor = PixelColor.fromRgb(80, 80, 80)) },
    state = listState,
    controller = listController,
    itemExtent = 12,
    separatorExtent = 1,
    cacheExtent = 1,
)
```

### `ListViewSeparatedBuilder`

固定高度的分隔列表 lazy API，只构造可见区 + `cacheExtent` 范围内的 item / separator。`itemExtent` 和 `separatorExtent` 都是必填参数，当前不支持变高 item 的 lazy 分隔列表。

真实 item 的滚动定位仍按 item index 工作：`controller.scrollItemIntoView(state, itemIndex)` 定位的是第 `itemIndex` 个 item，不会把 separator 算作 item。

### `SingleChildScrollView`

整个 child 作为一块滚动区域：

```kotlin
SingleChildScrollView(
    child = Column(children = veryLongList),
    state = listState,
    controller = listController,
)
```

### `PageView` / `PageViewBuilder`

## 状态辅助 widget

### `Builder`

延迟构建子树，让 child 能拿到自己的 `BuildContext`。lambda 类型是 `WidgetBuilder`（即 `(BuildContext) -> Widget` 的 typealias）：

```kotlin
Builder { context ->
    Text("W: ${MediaQuery.of(context).logicalWidth}")
}
```

### `StatefulBuilder`

最轻量的局部 state holder。lambda 类型是 `(BuildContext, StateSetter) -> Widget`：

```kotlin
StatefulBuilder { context, setState ->
    var count = 0
    Column(children = listOf(
        Text("$count"),
        OutlinedButton(text = "+1", onPressed = { setState { count++ } }),
    ))
}
```

`StateSetter` 是 `(() -> Unit) -> Unit` 的 typealias，即接受一个无返回 lambda 并触发重建。

> ⚠️ 注意：`StatefulBuilder` 的 lambda 在每次重建都会执行。把状态变量放在 lambda 内只对最简单的 demo 适用——真实业务请用 `ValueNotifier` 或 `StatefulWidget`。

### `ListenableBuilder`

订阅一个 `Listenable`，每当它通知就重建 child：

```kotlin
ListenableBuilder(listenable = myListController) {
    Text("CURRENT OFFSET: ${listState.scrollOffsetPx}")
}
```

### `ValueListenableBuilder<T>`

订阅 `ValueListenable<T>`，每次值变化就重建并把新值传给 builder：

```kotlin
val counter = ValueNotifier(0)

ValueListenableBuilder(listenable = counter) { _, value ->
    Text("$value")
}
```

### `AsyncBuilder<T>`

订阅 `PixelAsyncSource<T>` 并按当前 snapshot 重建子树。pixel-engine 不依赖
`kotlinx.coroutines`；source 是一个最小 callback 协议，调用方按需把 `Flow` /
`Future` / 任意异步框架适配进来。

```kotlin
AsyncBuilder(source = appListSource) { _, snapshot ->
    when (snapshot) {
        is PixelAsyncSnapshot.Loading -> Text("LOADING…")
        is PixelAsyncSnapshot.Success -> AppList(snapshot.value)
        is PixelAsyncSnapshot.Failure -> Text("ERR: ${snapshot.error.message}")
    }
}
```

`PixelAsyncSource<T>` 是 `fun interface`：

```kotlin
fun interface PixelAsyncSource<T> {
    fun subscribe(listener: (PixelAsyncSnapshot<T>) -> Unit): () -> Unit
}
```

适配 Coroutines `Flow` 示例：

```kotlin
fun <T> Flow<T>.asPixelAsyncSource(scope: CoroutineScope): PixelAsyncSource<T> =
    PixelAsyncSource { listener ->
        val job = scope.launch {
            catch { e -> listener(PixelAsyncSnapshot.Failure(e)) }
                .collect { listener(PixelAsyncSnapshot.Success(it)) }
        }
        return@PixelAsyncSource { job.cancel() }
    }
```

生命周期：`initState` 订阅、`didUpdateWidget` 在 source 变化时重订、`dispose`
取消。同步 emit 安全：source 在 `subscribe` 调用栈内立刻发的值会直接写入
snapshot（不走 `setState`，避免 element owner 未初始化时报错）。

辅助函数 `pixelAsyncSourceOf(value)` 用于把同步值包成立即 emit Success 的 source。

## 导航

### `PixelNavigator`

Flutter 风格的栈式导航 widget。`PixelNavigator` 保留 route stack，
`PixelNavigator.of(context)` 可在 route 子树里取得 `PixelNavigatorState`。

```kotlin
PixelNavigator(
    initialRoute = PixelRoute("home") { context ->
        Column(children = listOf(
            Text("HOME"),
            OutlinedButton(
                text = "DETAIL",
                onPressed = {
                    PixelNavigator.of(context).push(
                        PixelRoute("detail") { Text("DETAIL") },
                    )
                },
            ),
        ))
    },
    vsync = tickerProvider,
)
```

`PixelNavigatorState`：

```kotlin
state.push(route)
state.pop(): Boolean
state.maybePop(): Boolean
state.popToRoot()
state.popToRoot(animated = true)
state.replace(route)
state.replace(route, animated = true)
state.snapshot(): PixelNavigatorSnapshot
state.restore(snapshot, routeRegistry)
state.canPop
```

`PixelRoute(canPop = { ... })` 可拦截 `pop()` / `maybePop()`，用于未保存表单等确认场景。`PixelRoute(onEnter/onExit/onDispose)` 可观察 route 生命周期，dispose 会在离场转场完成后触发。
`state.snapshot()` 返回 `PixelNavigatorSnapshot`；`state.restore(snapshot, routeRegistry)` 可按 route name 栈恢复基础导航状态。

Route transition：

```kotlin
PixelRouteTransition.None
PixelRouteTransition.Fade
PixelRouteTransition.SlideHorizontal
PixelRouteTransition.SlideVertical
```

`SlideHorizontal` / `SlideVertical` 使用整数 offset 转场；`Fade` 在 alpha blend
落地后走真实半透明合成。route lifecycle、pop guard 和基础 snapshot/restore 已接入。

## 调试

仅在 dev / 调试构建中接入，生产构建建议不要绑定（频繁分配 `PixelHostFrameStats` 会污染分配热路径）。

### `PixelDebugOverlay`

调试 FPS / 帧时间小窗口。`stats == null` 时返回 0×0 占位。

```kotlin
PixelDebugOverlay(stats = currentStats)
```

视觉规格：黑底 + 灰边 + 1px padding，两行小字 `FPS …` / `MS …`。

### `PixelHostView.frameStatsObserver`

```kotlin
val statsNotifier = ValueNotifier<PixelHostFrameStats?>(null)
hostView.frameStatsObserver = { statsNotifier.value = it }
```

`PixelHostFrameStats`：

```kotlin
data class PixelHostFrameStats(
    val deltaMs: Long,           // 上一帧到当前帧的间隔
    val fpsAvg: Float,           // 最近 30 帧滑动平均（FPS_WINDOW = 30）
    val paintTimeNanos: Long,    // 当前帧 onDraw 体内 paint 耗时
    val frameCount: Long,        // 已观测的 onDraw 次数
)
```

observer 仅在非 null 时分配 `PixelHostFrameStats`；保持 paint 热路径零分配。

组合 overlay 的典型 widget 树：

```kotlin
Stack(children = listOf(
    mainContent,
    Positioned(top = 0, right = 0, child = ValueListenableBuilder(statsNotifier) { _, s ->
        PixelDebugOverlay(s)
    }),
))
```

### `PixelHostView.dumpElementTree(): String`

把当前 retained element tree 序列化成 ASCII 缩进字符串，供 log / panic / 调试面板使用。每个节点一行：

```
RootElement [widget=HostRootWidget render=RenderHostRoot]
  ColumnElement [widget=Column render=RenderFlex]
    TextElement [widget=Text render=RenderText listens=1]
```

主线程调用；不应高频调用。还没渲染过一帧时返回 `<no root>`。

## InheritedWidget

跨子树共享数据，并在数据变化时只重建依赖的子树：

```kotlin
class UserScope(
    val userName: String,
    override val child: Widget,
) : InheritedWidget(child = child) {
    override fun updateShouldNotify(old: InheritedWidget): Boolean =
        userName != (old as? UserScope)?.userName

    companion object {
        fun of(context: BuildContext): String =
            context.dependOnInheritedWidgetOfExactType<UserScope>()?.userName ?: "ANON"
    }
}

// 在树顶部注入：
UserScope(
    userName = "ALICE",
    child = MyApp(),
)

// 子节点读取：
Builder { context ->
    Text("HI ${UserScope.of(context)}")
}
```

SDK 内置的 `Directionality` / `MediaQuery` / `DefaultTextRasterizer` 都是 `InheritedWidget` 子类。

## 动画

> **import：** 动画 widget 在 `com.purride.pixelui.widgets.animated`，核心类型（Controller / Tween / Curves）在 `com.purride.pixelui.animation`。

pixel-engine 动画系统遵循**离散优先**原则：所有隐式动画 widget 默认使用 `Curves.Step(8)` 曲线，保持像素风格的格格感；若需要更平滑的过渡，可通过 `curve` 参数指定其他曲线。

### `TweenAnimationBuilder<T>`

通用隐式动画框架：当 `tween.end` 变化时自动从当前值补间到新值。

```kotlin
TweenAnimationBuilder(
    tween = IntTween(begin = 0, end = width),
    duration = 300.milliseconds,
    vsync = vsync,
    builder = { ctx, value ->
        Container(width = value, height = 16, borderColor = PixelColor.White)
    },
)
```

- `tween` — 任意 `Tween<T>`：`IntTween` / `EdgeInsetsTween` / `OffsetTween` / `PixelColorTween`
- `builder` — `(BuildContext, T) -> Widget`，每帧以当前插值调用
- `curve` — 默认 `Curves.Step(8)`；可替换为 `Curves.Linear` / `Curves.EaseOut` 等
- `onEnd` — 动画完成时回调

### `AnimatedContainer`

属性级别隐式动画。多个属性可共享一个 controller，state 内部管理：

```kotlin
AnimatedContainer(
    duration = 400.milliseconds,
    vsync = vsync,
    width = if (expanded) 80 else 20,
    height = 16,
    borderColor = if (expanded) PixelColor.fromRgb(255, 200, 0) else PixelColor.White,
    padding = EdgeInsets.all(if (expanded) 4 else 2),
)
```

支持属性：`width` / `height` / `padding` / `margin` / `borderColor`。属性为 `null` 时跳过插值。

### `AnimatedOpacity`

在三档阈值之间过渡。`0.5` 档会通过 `Opacity` 走真实 alpha blend。

```kotlin
AnimatedOpacity(
    opacity = if (visible) 1f else 0f,
    duration = 300.milliseconds,
    vsync = vsync,
    child = myWidget,
)
```

量化规则：`opacity < 0.25 → 0`；`0.25..0.75 → 0.5`；`> 0.75 → 1`。

### `Opacity`

对子树应用真实 alpha blend：

```kotlin
Opacity(
    opacity = 0.5f,
    child = Text("DIM"),
)
```

### `ClipRect`

按自身 layout box 裁剪子树 paint 和命中目标：

```kotlin
ClipRect(
    child = Transform.translate(IntOffset(-4, 0), Text("CLIPPED")),
)
```

### `Transform.translate`

整数平移子树，不做 scale / rotate：

```kotlin
Transform.translate(
    offset = IntOffset(2, 1),
    child = Text("MOVE"),
)
```

### `AnimatedPadding`

EdgeInsets 四边独立插值：

```kotlin
AnimatedPadding(
    padding = EdgeInsets.all(if (selected) 8 else 2),
    duration = 200.milliseconds,
    vsync = vsync,
    child = myWidget,
)
```

### `AnimatedAlign`

Alignment 在 t = 0.5 阈值切换（离散枚举不做连续插值）：

```kotlin
AnimatedAlign(
    alignment = if (atTop) Alignment.TOP_START else Alignment.BOTTOM_END,
    duration = 300.milliseconds,
    vsync = vsync,
    child = myWidget,
)
```

### `AnimatedPositioned`

只在 `Stack` 内使用。各边独立用 `IntTween` 插值：

```kotlin
Stack(children = listOf(
    AnimatedPositioned(
        duration = 400.milliseconds,
        vsync = vsync,
        left = if (atRight) 60 else 4,
        top = 4,
        child = Container(width = 20, height = 16, fillColor = PixelColor.fromRgb(255, 200, 0)),
    ),
))
```

### `AnimatedSwitcher`

child 变化（key 或 type 不同）时自动淡出旧 child / 淡入新 child：

```kotlin
AnimatedSwitcher(
    duration = 300.milliseconds,
    vsync = vsync,
    child = if (pageA) pageWidgetA else pageWidgetB,
)
```

- 通过 `key` 区分 child 身份；相同 key 不触发切换
- 淡出 / 淡入复用与 `AnimatedOpacity` 相同的阈值逻辑

### `AnimatedBuilder`

性能取向的动画订阅 widget——把不变的子树通过 `child` 参数静态传入，builder
只负责构造"包住 child 的会变的部分"。

```kotlin
AnimatedBuilder(
    animation = controller,
    child = Text("HELLO"),
) { _, child ->
    Padding(all = (controller.value * 8).toInt(), child = child!!)
}
```

与 `ListenableBuilder` 对比：

- `ListenableBuilder` 每次 listener 触发都让 builder 重建整棵子树。
- `AnimatedBuilder` 把 `child` 在外层只构造一次，按引用传给 builder；
  child 子树在 Element 层按 `===` reconcile，整体复用。

[`animation`] 类型放宽到任意 [`Listenable`]，与 `ListenableBuilder` 对齐——
名字沿用 Flutter `AnimatedBuilder` 习惯，配合 `PixelAnimationController`
（也是 `ChangeNotifier`）即可。

### `AnimatedSprite`

按固定 FPS 推进 `PixelSpriteSheet` 的 frame index。内部持有 ticker，`fps <= 0`
会抛 `IllegalArgumentException`。

```kotlin
AnimatedSprite(
    sheet = runnerSheet,
    fps = 8,
    loop = true,
    playing = true,
    vsync = tickerProvider,
)
```

- `loop = true`：到末帧后回到首帧。
- `loop = false`：到末帧后停在末帧。
- `playing = false`：保持当前 frame，不推进 ticker。

### `PixelTickerProvider.createTicker(maxFps = …)`

像素引擎专属：把单个 ticker 限制在 N FPS，drop 中间帧。

```kotlin
val ticker = provider.createTicker(maxFps = 15) { elapsedNanos ->
    // 每秒最多 15 次（不强制等间距，但保证最低间隔）
}
```

- `maxFps == null`（默认）：每个 vsync 都派发。
- `maxFps > 0`：只有距上次派发 ≥ `1_000_000_000 / maxFps` 纳秒时才派发，
  中间帧丢弃。
- `elapsedNanos` 仍是 ticker 启动起累积的真实时间——`PixelAnimationController`
  使用低 FPS ticker 时，0→1 的步数 ≈ `duration × maxFps`，符合像素风
  离散感取向。
