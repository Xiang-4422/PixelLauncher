# 颜色与样式

当前 `pixel-engine` 的颜色模型已经收敛为一条路径：

> widget 树直接渲染到 ARGB `PixelBuffer`，公开 API 使用 `PixelColor`，不再有 `PixelTone` / `PixelPalette` / `ThemeData` / `colorMode`。

这意味着 SDK 本身不再内置“主题 token 自动派生样式”的层。应用可以在自己的业务层定义主题对象，再把颜色传给 `Text` / `Container` / `OutlinedButton` / `TextField` 等 widget。

---

## PixelColor

`PixelColor` 是 ARGB 32-bit value class，与 Android `Bitmap.Config.ARGB_8888` 的像素格式一致。

```kotlin
val white = PixelColor.White
val black = PixelColor.Black
val clear = PixelColor.Transparent
val amber = PixelColor.fromRgb(255, 180, 40)
val translucent = PixelColor.fromArgb(128, 255, 255, 255)

amber.alpha
amber.red
amber.green
amber.blue
amber.argb
```

`PixelBuffer` 内部每个逻辑像素就是一个 ARGB `Int`。透明像素显示为宿主绘制的像素格栅 / 背景。

---

## 宿主背景与格栅色

宿主级颜色由 `PixelHostSetupConfig` 和 `PixelHostView` 控制：

```kotlin
val setup = createPixelHostSetup(
    context = this,
    config = PixelHostSetupConfig(
        backgroundColor = PixelColor.Black,
        content = { AppRoot() },
    ),
)

setup.hostView.pixelGridColor = PixelColor.fromRgb(17, 17, 17)
```

- `backgroundColor`：整个 Android View 的底色，也覆盖屏幕外 bezel 区域。
- `pixelGridColor`：逻辑像素未绘制内容时的格栅 / 面板底色。
- `setPixelGapEnabled(enabled)`：是否显示逻辑像素间隙。
- `setPixelGapRatio(ratio)`：间隙比例，`0f..1f`。

运行时修改这些属性会触发重绘。

## 文本样式

`TextStyle` 是 `PixelTextStyle` 的别名。颜色直接用 `PixelColor` 指定：

```kotlin
Text(
    "HELLO",
    style = TextStyle(
        color = PixelColor.fromRgb(180, 255, 190),
        letterSpacing = 1,
        lineSpacing = 1,
        fontScale = 1,
    ),
)
```

也可以直接传 `Text(color = ...)` 覆盖样式中的颜色：

```kotlin
Text("WARN", color = PixelColor.fromRgb(255, 200, 0))
```

字体栅格器优先级：

1. `TextStyle(textRasterizer = ...)`
2. widget 树中的 `DefaultTextRasterizer`
3. `PixelHostView.textRasterizer`
4. `PixelBitmapFont.Default`

## 容器与按钮

容器直接接受填充色和边框色：

```kotlin
Container(
    width = 64,
    height = 20,
    fillColor = PixelColor.fromRgb(12, 18, 24),
    borderColor = PixelColor.fromRgb(120, 220, 255),
    padding = EdgeInsets.all(2),
    child = Text("STATUS"),
)
```

`DecoratedBox` 只做填充 / 边框装饰：

```kotlin
DecoratedBox(
    fillColor = PixelColor.fromRgb(0, 0, 0),
    borderColor = PixelColor.fromRgb(255, 200, 0),
    child = Text("BORDERED"),
)
```

按钮样式：

```kotlin
OutlinedButton(
    text = "APPLY",
    onPressed = { apply() },
    style = ButtonStyle(
        fillColor = PixelColor.fromRgb(10, 10, 10),
        borderColor = PixelColor.fromRgb(255, 200, 0),
        textStyle = TextStyle(color = PixelColor.White),
    ),
)
```

`OutlinedButton(fillColor = ..., borderColor = ...)` 会覆盖 `style` 中对应颜色。

---

## 输入框样式

`TextFieldStyle` 使用 `PixelColor` 配置边框、光标、选区和 composition 下划线：

```kotlin
TextField(
    state = inputState,
    controller = inputController,
    placeholder = "TYPE",
    style = TextFieldStyle(
        borderColor = PixelColor.fromRgb(120, 120, 120),
        focusedBorderColor = PixelColor.fromRgb(255, 200, 0),
        cursorColor = PixelColor.fromRgb(255, 200, 0),
        selectionColor = PixelColor.fromRgb(80, 120, 255),
        compositionColor = PixelColor.fromRgb(255, 200, 0),
        textStyle = TextStyle(color = PixelColor.White),
        placeholderStyle = TextStyle(color = PixelColor.fromRgb(120, 120, 120)),
    ),
)
```

`TextField(fillColor = ..., borderColor = ...)` 同样会覆盖 style 中对应颜色。

## 应用层主题建议

SDK 不再内置 `ThemeData`，但应用可以保留自己的主题数据类：

```kotlin
data class AppPixelTheme(
    val background: PixelColor,
    val grid: PixelColor,
    val text: PixelColor,
    val dim: PixelColor,
    val accent: PixelColor,
)

val green = AppPixelTheme(
    background = PixelColor.Black,
    grid = PixelColor.fromRgb(8, 37, 13),
    text = PixelColor.fromRgb(151, 255, 167),
    dim = PixelColor.fromRgb(80, 160, 90),
    accent = PixelColor.fromRgb(255, 220, 120),
)
```

在宿主和 widget 树中显式传入：

```kotlin
setup.hostView.backgroundColor = theme.background
setup.hostView.pixelGridColor = theme.grid

Text("HOME", color = theme.text)
Container(borderColor = theme.accent)
```

这种做法让 engine 保持简单，业务层保留完整审美和语义控制。
