# pixel-engine 0.1.0-SNAPSHOT 发布清单

本文只保留 `0.1.0-SNAPSHOT` 的历史内部发布状态，不再代表当前候选。1.0 状态见
[1.0.0 发布清单](1.0.0发布清单.md)，长期版本、弃用和迁移规则见
[发布与兼容策略](发布与兼容策略.md)。

## 1. 发布定位

- artifact：`com.purride:pixel-engine:0.1.0-SNAPSHOT`
- 当前阶段：内部 `0.x` Android-only 像素 UI SDK。
- 兼容承诺：source / binary compatibility best-effort。
- 不承诺：Material / Cupertino 组件库、Flutter 全 API、跨平台。

## 2. 当前 SDK 面

- Runtime：widget tree、retained state、layout、render、input、focus、semantics、entry-backed typed navigation、版本化 route 恢复、嵌套/多返回栈、animation。
- Android host：`PixelHostView`、`PixelHostSetup`、IME、clipboard、discrete/predictive back、haptic、saved state、lifecycle、insets。
- Testing：SDK 可用 `PixelTester`、finder、gesture、text input、pixel buffer 断言。
- Diagnostics：`PixelDebugOverlay`、inspector、兼容 frame stats、默认关闭的完整帧阶段/工作量/丢帧归因、错误边界。
- Components：Text、RichText、TextField、buttons、ListTile、selection、slider、tabs、overlay feedback、empty state、slidable、scaffold。
- Resource：bitmap、sprite sheet、glyph pack、resource manifest、resource cache。

## 3. 本快照已记录的破坏性变更

根目录 `CHANGELOG.md` 已记录：

- `advanced.Pixel*` 从指向 internal 的 typealias 重置为真实公共 RenderObject SPI；旧
  snapshot 二进制必须按迁移指南重新编译
- `PixelHostView.backgroundColor -> bezelColor`
- `PixelHostView.pixelGridColor -> offPixelColor`
- `PixelPagerController.startDrag` 增加 `viewportSizePx`

## 4. 已暴露但尚未达到 1.0 行为契约的组件

以下组件已经进入当前 `0.1.0-SNAPSHOT` public API，但锚点、焦点、输入和碰撞行为尚未达到
`1.0.0` 稳定承诺，具体整改见 `pixel-engine/docs/1.0-GOAL.md` M4/M5：

- `Menu`
- `Popover`
- `Dropdown`
- `Tooltip`
- `ShortcutHint`

在这些行为通过验收前，消费者不应把它们视为已经稳定的 1.0 契约。

## 5. 必跑门禁

默认无设备发布门禁：

```bash
./tools/pixel-release-check.sh
```

该门禁覆盖：

- public API baseline
- binary API baseline
- Metalava v4 current/released compatibility 与 stable/internal 边界报告
- KDoc coverage
- 工作树及 APK/AAR secret scan
- pixel-engine 单测、lint、Release AAR
- pixel-demo 单测、assemble
- app 单测、lint、Debug/Release APK
- 独立 Maven host consumer、外部 RenderObject SPI consumer、RouteEntry 正向/类型负例 consumer，
  以及旧消费者二进制运行测试
- AGP `8.10.1`/Gradle `8.11.1`/Kotlin `2.2.10`/compileSdk `36` 最低消费者与
  AGP `9.1.1`/Gradle `9.3.1`/内置 Kotlin/compileSdk `36.1` 推荐消费者矩阵
- 九个坐标的 AAR/POM/Gradle module/sources/Javadoc/consumer rules 与传递依赖发布物校验
- JVM perf smoke 和生命周期 soak
- mkdocs build

## 6. 补充检查

各项门禁也可以单独运行以缩短本地定位时间：

```bash
./tools/pixel-render-spi-compatibility.sh
./tools/pixel-route-entry-compatibility.sh
./tools/pixel-previous-binary-compatibility.sh
./tools/pixel-consumer-compatibility-matrix.sh
./tools/pixel-sdk-consumer-smoke.sh
```

```bash
./tools/pixel-perf-smoke.sh
./tools/pixel-soak-test.sh
```

真实设备检查依赖 ADB，不作为默认门禁：

```bash
./tools/pixel-device-smoke.sh
ANDROID_SERIAL=<api-34+-serial> ./gradlew :pixel-engine:connectedDebugAndroidTest --no-daemon
```

后一个任务验证真实 Android `BackEvent` / Window dispatcher、predictive start/progress/cancel/
commit 和 multi-stack Bundle。API 33 以下设备不能作为 predictive progress 验收证据。
