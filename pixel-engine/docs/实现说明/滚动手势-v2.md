# 滚动手势 v2 设计

## Summary

当前滚动、fling、bounce 参数和 PageView/ListView 嵌套仲裁已能覆盖基础场景，但一次手势的归属状态还隐含在 host 分发逻辑中。v2 目标是把手势 session 显式建模，稳定 snap、overscroll 和嵌套 handoff 语义。

## Public API

保留 `PixelScrollPhysics` 现有字段，先补文档和测试语义：

- `minFlingVelocityPxPerSecond`：低于阈值不进入 settling。
- `decelerationPxPerSecondSquared`：fling 每帧减速。
- `snapEpsilonPx`：接近边界时吸附到 0 或 max。
- `bounceEnabled` / `bounceOverscrollLimitPx` / `bounceResistance`：仅影响 drag/settling 边界。

新增 internal 类型，不作为页面层 API：

```kotlin
internal class NestedScrollSession
```

## Internal Model

`NestedScrollSession` 保存一次触摸序列的归属：

- pointer id / start position / last position。
- candidate targets：pager、list、text input。
- active owner：none / pager / list / textInput。
- consumed delta 和 remaining delta。
- edge handoff 状态：childAtStart、childAtEnd、parentCanConsume。

`PixelHostView` 只负责生命周期入口、坐标映射、VelocityTracker 与 IME bridge；具体仲裁由独立 internal `PixelHostGestureRouter`、`NestedScrollSession` 和纯 Kotlin `PixelHostGestureRouterModel` 测试入口共同覆盖。

## Gesture Semantics

- 未超过 touch slop 前不锁定 owner。
- 一旦 owner 锁定，除 edge handoff 外不在同一手势中反复切换。
- child list 能消费时优先 child；到边界且 parent pager 可消费时 handoff 给 parent。
- TextField tap 聚焦；拖动时只做最小 selection 更新，不抢 pager/list owner。
- fling 只交给最后 active owner。

## Compatibility

- 不改变 `PixelHostSetupConfig` 的现有手势策略注入方式。
- 不改变 `ListViewBuilder`、`PageView`、`TextField` 调用方式。
- 不把旧 `PixelRenderer` 或 app 业务语义接入 engine。
- 当前阶段只重构 host 内部手势状态，后续再考虑公开更细粒度策略。

## Test Plan

- `PageView + ListView` 嵌套：child 可滚时 list 消费，child 到边界后 pager 接管。
- `PageView + ListView + TextField`：点击输入框聚焦，输入框内拖动更新 selection，拖动空白区滚动。
- fling 速度 NaN / Infinity / 低速阈值回归。
- bounce 开关和 overscroll limit 回归。
- emulator 手测 demo stress scene，记录打开、拖动、fling、输入、取消触摸流程。
